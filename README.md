# blog.dztang.net

Personal blog of **Daoze Tang**. Built with [Eleventy](https://www.11ty.dev/) and a hand-rolled pixel-art SCSS design system shared with my [homepage](https://github.com/DaozeTang/DaozeTang.github.io); full-text search by [Pagefind](https://pagefind.app/), comments by [giscus](https://giscus.app/); deployed to GitHub Pages via GitHub Actions on every push to `main`.

## Develop

```bash
npm install
npm run serve     # dev server with live reload (search index not built)
npm run build     # production build into _site/ + Pagefind index
npm run new-post -- "Post Title"
npm run theme:check   # pixel design-system guard (also runs before build)
```

Fenced code blocks need a Prism language tag to be highlighted, e.g. ``` `bash` ``, ``` `python` ``, ``` `yaml` ``, ``` `ini` `` for systemd/screenrc/registry files, ``` `batch` ``, ``` `powershell` ``, ``` `latex` ``. Use ``` `text` `` for command output, error messages, URLs and other non-code samples so they stay deliberately unhighlighted instead of appearing broken.

## Design system (pixel, 16 colours, no blur)

Everything renders on a 4px grid. Shared with the homepage and kept byte-identical by `npm run theme:check`:

| Partial | Role |
| --- | --- |
| `src/styles/_tokens.scss` | Palette, type scale, spacing, hard shadows, stepped motion |
| `src/styles/_fonts.scss` | Self-hosted @font-face declarations |
| `src/styles/_base.scss` | Reset, stage backdrop, icons, print rules |
| `src/styles/_pixel.scss` | Beveled panels, CRT screens, detection overlay |
| `src/styles/_layout.scss` | Shell, section headers, sticky rails |
| `src/styles/_chrome.scss` | Masthead, navigation, footer HUD |
| `src/styles/_ui.scss` | Buttons, chips, dialogs, pager, forms |
| `src/styles/_prose.scss` | Long-form article typography and syntax colours |
| `src/styles/_animations.scss` | Stepped keyframes, reveal, toast |
| `src/styles/_responsive.scss` | Breakpoints, touch targets |
| `src/styles/_a11y.scss` | High-contrast and forced-colours overrides (imported last) |

Blog-only partials: `_cover`, `_feed`, `_post`, `_archive`, `_tools`, `_search`, `_pages`.

**Type.** `Silkscreen` (8px grid, Latin) for labels and numerals, `Cubic 11` (12px grid, CJK + Latin) for headings and Chinese display text, `Noto Sans SC` for body copy at reading sizes, `VT323` for oversized terminal numerals. Pixel fonts are self-hosted from `src/assets/fonts/` (SIL OFL 1.1, licence files included) so Chinese readers never wait on Google Fonts. Sizes stay on the grid: Silkscreen at multiples of 8, Cubic 11 at multiples of 12.

**Icons.** One inline sprite (`src/partials/sprite.liquid`, [Pixelarticons](https://github.com/halfmage/pixelarticons), MIT) rendered with `shape-rendering: crispEdges`. Use `<svg class="ico"><use href="#i-search"></use></svg>`.

**Art.** `src/scripts/pixel-scene.js` paints the cover's 8-bit workshop canvas at 8 fps with a `<canvas id="scene" data-scene="workshop">`; detection boxes are DOM overlays so their labels stay sharp. The favicon is generated by `python3 scripts/pixel-art.py` (Pillow), as is the 1200×630 social card in `src/assets/og.png`.

**Motion.** Every transition runs on `steps()`; `prefers-reduced-motion` freezes the canvas, marquee and reveals. Theme switches use a stepped dither shutter. The search affordance is a real link to `/search/` that upgrades into a dialog when scripts run; the lightbox supports arrows, keyboard and swipe; code blocks are wrapped so their copy button stays put while the code scrolls.

**Index pages.** `/archive/` is the hub: category cards carry a share bar and a destination arrow, the tag cloud collapses, and the timeline is a numbered ledger. `/tags/` and `/categories/` list every term with counts; the tag index has a live filter that hides empty bands (the toolbar ships hidden, so a blocked script still shows the full index). Term pages carry the same record stamp as the rest of the site. Code blocks that overflow horizontally get a right-edge fade and a "→" cue until scrolled to the end; touch devices always show the row arrows that hover normally reveals.

**Accessibility.** axe-core reports no WCAG 2.1 A/AA violations on the index, article, archive, tags, categories, tools, search and 404 pages. Headings are normalised to start at `<h2>` under the post title, decorative permalinks are out of the tab order, prose links are underlined rather than colour-only, and the theme icon is selected by CSS from `data-theme-mode` so it is correct even without JavaScript.
